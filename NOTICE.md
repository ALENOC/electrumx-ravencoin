# Maintained-fork notice

This repository is an ALENOC-maintained fork of ElectrumX adapted for Ravencoin.
It contains upstream ElectrumX code, Ravencoin conversion and asset work from
the Electrum-RVN-SIG community, and later maintained changes. It is not an
official Ravencoin or Electrum release.
